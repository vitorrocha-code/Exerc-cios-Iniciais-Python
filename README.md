# Exercícios – Introdução ao Python (Fundação Bradesco)

Repositório com os exercícios práticos desenvolvidos durante o curso **Introdução ao Python**, da Fundação Bradesco. Aqui estão registrados os primeiros passos da minha jornada como estudante de Desenvolvimento de Sistemas na ETEC, praticando lógica de programação com Python.

## 📂 Exercícios

| Arquivo | Descrição |
|---|---|
| `calculadora.py` | Calculadora simples com as quatro operações básicas (soma, subtração, multiplicação e divisão). |
| `fizzbuzz.py` | Implementação do clássico desafio FizzBuzz, usado para praticar estruturas condicionais e loops. |
| `maior_menor.py` | Programa que identifica o maior e o menor valor entre números informados. |
| `tabuada.py` | Gera a tabuada de um número informado pelo usuário. |
| `verificador_numerico.py` | Verifica propriedades de um número (par/ímpar, positivo/negativo, etc.). |
| `SistemaCadastro.py` | Sistema de cadastro simples, unindo entrada de dados, estruturas condicionais e organização de informações em um programa mais completo. |

## 🎯 Objetivo

O foco deste repositório é fixar os fundamentos da lógica de programação — variáveis, condicionais, loops, funções e manipulação de dados — antes de avançar para tópicos mais complexos como estruturas de dados, orientação a objetos e desenvolvimento web.

## 🛠️ Tecnologias

- Python 3
